## Published Papers

### AI-Driven Algorithmic Trading: Integrating Machine Learning, Hybrid Technical Indicators, and Risk Management for Momentum Strategies

| | |
|---|---|
| **Journal** | International Journal of Engineering and Computer Science (IJECS), Vol. 14 No. 11 |
| **Published** | November 24, 2025 |
| **DOI** | [10.18535/ijecs.v14i11.5335](https://doi.org/10.18535/ijecs.v14i11.5335){:target="_blank"} |

Integrates supervised machine learning with hybrid technical indicators (VWAP, MACD, RSI, Bollinger Bands) and dynamic risk management for momentum trading. Returns are 14% higher and drawdown 7% lower than conventional rule-based approaches, and the Sharpe ratio improves from 0.8 to 1.7.

- Sub-second latency trading system with 67% accuracy (vs. 54% baseline)
- Momentum-specific signal fusion with adaptive weighting
- Integrated real-time risk management with momentum-aware controls
- Data validation across multiple market data providers

*Keywords: algorithmic trading, machine learning, momentum trading, technical indicators, risk management, real-time systems, VWAP, quantitative finance*

### High-Throughput Cloud-Native Messaging Architectures: Design and Performance Analysis of Pub/Sub Microservices with Kubernetes and Azure Event Hub

| | |
|---|---|
| **Journal** | International Journal of Advance Research in Computer Science and Management Studies (IJARCSMS), Vol. 13 Issue 11 |
| **Published** | 2025 |
| **DOI** | [10.61161/ijarcsms.v13i11.1](https://doi.org/10.61161/ijarcsms.v13i11.1){:target="_blank"} |

Empirical performance analysis of high-throughput messaging on Azure Kubernetes Service (AKS) and Azure Event Hub in a publish-subscribe model. Shows how cloud-native designs handle large-scale ingestion and real-time event streaming with minimal latency and 99.9%+ reliability.

- Scalability, throughput, and latency evaluated under varying load
- Operational efficiency through Kubernetes auto-scaling and partition-based distribution
- Best practices for observability, security, and automation
- Reference architecture for mission-critical enterprise applications

*Keywords: cloud-native architecture, microservices, Kubernetes, Azure Event Hub, pub/sub, event-driven systems, distributed systems, high-throughput processing*
